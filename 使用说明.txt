GitHub 项目整理 · 使用说明（中文版）
========================================

一、这是什么
这是一个放在你电脑里的网页，用来看你收藏过的 GitHub 项目，
以及你自己三个仓库的检查结果。
不需要安装，不需要联网，双击就能看。


二、怎么打开（任选一种）
方法一：双击本文件夹里的「打开工作台.bat」。
方法二：双击本文件夹里的「GitHub项目整理」快捷方式。
方法三：双击 index.html，用浏览器打开。
方法四（推荐）：
        把本文件夹里的「GitHub项目整理」快捷方式，
        右键 → 复制，然后到桌面 → 右键 → 粘贴。
        以后在桌面双击它就行，和普通软件一样。


三、页面上有什么
顶部有三个标签，点一下就切换：

1）收藏的项目
   你星标（收藏）过的项目，已经按类别分好。
   · 上面搜索框：输入「照片」「网关」「安卓」等字词就能筛。
   · 下面一排标签：点一下只看某一类。
   · 右上角：可以按星数从多到少排序。
   · 点任意一行：直接打开那个项目的网页。

2）我的仓库
   你自己名下的三个仓库，显示：
   · 成熟度评分（满分一百）
   · 已经做好的部分（绿色）
   · 还需要补的部分（黄色、红色）
   每条都写了具体怎么做。

3）体检建议
   列出需要处理的事，比如：
   · 哪些收藏已经被作者停止维护
   · 哪些收藏重复了
   · 哪些收藏没有写介绍


四、看更详细的文字报告
双击「仓库审计报告.md」。
如果打开是乱码或者一大段代码：
右键 → 打开方式 → 记事本。


五、什么时候需要更新数据
你的收藏或仓库有变化之后：
1. 双击「更新.ps1」（如果双击没反应，右键 → 使用 PowerShell 运行）。
2. 等窗口自己跑完，会重新打开网页。
注意：这一步需要联网。


六、文件夹里其他东西是什么（平时不用管）
data 文件夹     ：抓下来的原始数据。
scripts 文件夹  ：自动抓取和生成网页的小程序。
config 文件夹   ：分类规则，想改分类再动。
README          ：更详细的说明，可以看也可以不看。


七、遇到问题怎么办
1. 双击 index.html 打开是记事本、显示一堆代码：
   右键 → 打开方式 → 选择 Edge 或 Chrome 浏览器。
2. 网页打开是一片空白：
   说明还没生成，双击「更新.ps1」重新生成一次。
3. 双击 bat 一闪而过：
   没影响，直接双击 index.html 效果一样。
4. 想改分类、改颜色、改页面：
   看 README，或者直接找我改。


（完）
